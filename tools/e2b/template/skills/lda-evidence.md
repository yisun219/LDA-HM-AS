# 证据怎么写

每份门证据都含五要素:

1. **执行的命令**(可原样重跑);
2. **原始输出的关键行**(不转述,照抄);
3. **作业编号或产物路径**(沙箱写 sandbox_id 与模板名;没有调度作业就显式写明);
4. **为什么它支撑结论**(把数字和判据接上);
5. **最终状态与退出码**(逐步 rc)。

配套纪律:

- **产数脚本先 git 提交再运行**——判据进历史在数据之前,事后放松会被查出来;
- 每份证据文件登记 sha256 到 `evidence/HASHES.tsv`,防作弊检查认指纹不认口号;
- 临时文件只放卡内 `work/`,收尾清空;被证据引用的原始数据放 `evidence/`,永不删除;
- 收尾把 `.auto/state/GATES.tsv` 更新到与证据一致:通过 / 失败 / 无法判断 / 不适用,
  "不适用"必须带一句理由;闭合不了的写进 `NOTES.md`,如实留 TODO;
- 结论句不得强于观测:"没测出差别"不能写成"证明了没有差别",要连着可分辨下限(MDE)一起写。
