# 八项兼容检查怎么做

收敛条件是这八条全部不失败;不适用的必须写一句理由,空白 ≠ 不适用。

| 边界 | 机械做法 |
|---|---|
| 二进制 ABI | `readelf --dyn-syms` 导出符号逐一比对(零删改);`abidiff --harmless` 做类型级差分;SONAME 与符号版本不许变 |
| FFI | 在**原版**上编译好调用程序,**不重新编译**直接在优化版上跑,输出一致(如 python3 绑定、pkg-config 消费方) |
| 行为 | 同输入两版输出逐字节比;命令行参数、退出码、数据文件格式不变;错误路径也要覆盖(畸形输入) |
| 配置 | 用户既有配置经安装→升级→卸载→重装后完好 |
| 硬件覆盖 | 多种拓扑真实验证;只有一种拓扑就如实记"无法判断",别写"很可能没事" |
| 系统升级 | `dpkg --compare-versions` 验版本序 + 真跑一次官方安全更新覆盖 |
| 安全默认值 | 缓解措施、沙箱、签名验证默认不弱化;弱化了就只能 opt-in |
| 结果等价 | 产物(生成的文件/缓存/输出)逐字节比 |

**每条检查启用前先打坏样本**:故意做一个应当被拦下的样本(改一个符号、换一个字节),
检查必须报错;抓不住坏样本的检查不算数,证据里要留这次自检的记录。
