# Glossary

- **Campaign**: outer controller selecting and coordinating package Missions.
- **Mission**: one package, one isolated E2B Sandbox, one Humanize2 Builder/Reviewer flow.
- **Builder**: persistent Humanize2 session that edits only allowed production paths.
- **Reviewer**: fresh Humanize2 session returning strict Pydantic output without edits.
- **Fence**: deterministic programmatic compatibility, provenance, security, or measurement check.
- **Micro benchmark**: local library/function measurement with raw samples, median, MAD, and checksum.
- **Package E2E**: real consumer workload for one package.
- **Portfolio**: clean candidate sandbox containing all accepted package artifacts.
- **Trace**: Humanize cycle/trace evidence, audited for commands and policy violations.
